## 📖 Sobre o Projeto

O **Simulador de Sistema de Login** é uma aplicação desenvolvida com HTML, CSS e JavaScript com o objetivo de praticar conceitos de autenticação e validação de formulários no front-end.

A aplicação realiza uma simulação simples de login utilizando campos de usuário e senha, verificando as informações digitadas para permitir ou bloquear o acesso.

O projeto foi criado como prática para reforçar conhecimentos em lógica de programação, manipulação do DOM e validação de dados com JavaScript.

---

## 🚀 Funcionalidades

- Campo de usuário
- Campo de senha
- Validação de login
- Mensagens de erro e sucesso
- Interface simples e intuitiva
- Interatividade com JavaScript
